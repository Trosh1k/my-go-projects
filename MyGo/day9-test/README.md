# День 9: Логирование, тестирование и graceful shutdown

Сегодня мы превратили наш REST API в более надёжное и профессиональное приложение:
- Добавили **структурированное логирование** (через `logrus`) с уровнями и полями.
- Написали **юнит-тесты** для обработчиков с использованием `httptest`.
- Реализовали **graceful shutdown** — корректное завершение сервера по сигналу (Ctrl+C).

# Что было сделано

# 1. Логирование запросов (middleware)
- Каждый входящий запрос логируется с методом, путём и IP-адресом.
- Используются разные уровни: `Info`, `Warn`, `Error`.
- Ошибки логируются с контекстом (`WithError`).

# 2. Тестирование обработчиков
- Написаны тесты для `GET /tasks`, `POST /tasks`, `GET /tasks/{id}`, `PUT /tasks/{id}`, `DELETE /tasks/{id}`.
- Тесты используют `httptest.NewRecorder()` и `httptest.NewRequest()`.
- Проверяются статусы ответов (200, 201, 404, 204).

# 3. Graceful shutdown
- Сервер завершается плавно при получении сигнала (Ctrl+C).
- Даётся **5 секунд** на завершение текущих запросов.
- База данных закрывается корректно перед выходом.
