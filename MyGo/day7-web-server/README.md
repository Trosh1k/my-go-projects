# День 7: REST API для управления задачами на Go

Простой RESTful‑сервер на Go с хранением данных в памяти. Реализованы все CRUD‑операции для задач (To‑Do). Данные защищены мьютексом (`sync.Mutex`) для конкурентного доступа.



# Запуск

1. Убедитесь, что установлен Go (версия 1.18+).
2. В терминале перейдите в папку с `API.go`.
3. Запустите сервер:
   ```bash
   go run API.go
