# День 3: Структуры и методы (Библиотека)

# Что изучал
- Объявление структур (`type Book struct`).
- Создание методов с получателем (`func (b Book) Info()`).

- Реализацию интерфейса `fmt.Stringer` для красивого вывода.
- Основы работы со слайсами и изменением состояния книг.
