# День 10: Переменные окружения, структурированное логирование и Docker

Сегодня мы сделали наш проект **готовым к продакшену**:
- Научились настраивать приложение через **переменные окружения** (порт, путь к БД, уровень логов).
- Перешли на **структурированное логирование** с `logrus` (уровни, поля, JSON-формат).
- Написали **Dockerfile** и запустили приложение в контейнере.

# Что было сделано

# 1. Переменные окружения
- Все настройки теперь читаются из `env`.
- Можно менять поведение без перекомпиляции: `PORT=9090 go run API.go`.
- Используется функция `getEnv(key, defaultValue)`.

# 2. Структурированное логирование (logrus)
- Заменён стандартный `log` на `logrus`.
- Добавлены уровни: `Debug`, `Info`, `Warn`, `Error`, `Fatal`.
- Логи содержат поля: `method`, `path`, `ip`, `error`.
- Уровень логирования задаётся через `LOG_LEVEL`.

# 3. Docker
- Написан `Dockerfile` с **multi-stage сборкой** (облегчённый образ на Alpine).
- Контейнер запускается с пробросом порта и переменными окружения.
- Образ весит ~15 МБ (вместо ~300 МБ без оптимизации).
